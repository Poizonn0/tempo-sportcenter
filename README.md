# SportCenter

Адаптивный демонстрационный сайт спортивного центра: Flask + SQLite, русскоязычный интерфейс, сине-голубая палитра со светлой и тёмной темами, регистрация участников, расписание и запись на занятия, личный кабинет, панель администратора и CSV-отчёт.

## Запуск на Windows

Нужны Python 3.11 или новее и PowerShell.

1. Открой папку `SportCenter` в VS Code через **File → Open Folder**.
2. Открой терминал VS Code (**Terminal → New Terminal**) и выполни:

   ```powershell
   .\run.ps1
   ```

   При первом запуске скрипт создаст виртуальное окружение, установит Flask и подготовит базу `instance/sportcenter.db` с демо-расписанием.
3. Дождись сообщения Flask в терминале и открой **http://127.0.0.1:5000** в браузере. Адрес без `:5000` не откроет этот сервер.

В VS Code можно также открыть вкладку **Run and Debug**, выбрать `SportCenter (Flask)` и нажать зелёную кнопку запуска.

Для остановки сервера нажми `Ctrl+C` в окне PowerShell.

## Доступ администратора

- Email: `admin@sportcenter.local`
- Пароль: `admin123`

После входа появится ссылка «Админ-панель». Там можно добавлять занятия, смотреть участников и бронирования, скачать CSV-отчёт.

Создать учётную запись клиента можно через «Создать аккаунт».

## Доступ по ссылке через Cloudflare Quick Tunnel

Quick Tunnel предназначен для демонстрации. Для постоянно работающего сайта понадобится размещение на сервере и отдельная настройка домена/базы.

1. В первом окне запусти сайт командой ` .\run.ps1 `.
2. Во втором окне PowerShell из этой папки выполни ` .\tunnel.ps1 `. Скрипт использует `tools/cloudflared.exe`, если он есть, или установленную в Windows команду `cloudflared`.
3. Открой выданную Cloudflare ссылку `https://....trycloudflare.com` на телефоне. Компьютер и оба процесса должны оставаться включёнными.

Quick Tunnel выдаёт временный адрес, который меняется при следующем запуске. Не публикуй через него реальные персональные данные. Демонстрационный администратор имеет известный пароль; перед публичным показом измени пароль и не используй базу с личными данными.

## Постоянная бесплатная ссылка Cloudflare Workers

Для постоянного адреса используется Workers `workers.dev` и база D1. Сайт опубликован: [https://tempo.sportcenter.workers.dev](https://tempo.sportcenter.workers.dev). Собственный домен покупать не требуется.

Приложение развернуто как Cloudflare Worker, данные расписания, пользователей и записей находятся в D1. Если папки `tools/node-portable` ещё нет, один раз выполни `uv run python tools/bootstrap_node.py`. Команды Wrangler запускай через `cloudflare.ps1`.

Чтобы опубликовать обновление сайта (команды выполнять из папки проекта):

```powershell
uv run tools/package_worker.py
.\cloudflare.ps1 deploy
```

Wrangler авторизован, а случайный `SESSION_SECRET` уже сохранён в Cloudflare. Миграция создаёт демонстрационного администратора `admin@sportcenter.local` с паролем `admin123` — смени пароль, если будешь использовать сайт за пределами демонстрации.

## Структура

- `src/app.py` — маршруты, аутентификация и работа с базой.
- `app.py` — точка запуска локальной версии.
- `templates/` — HTML-страницы.
- `static/style.css` — базовые стили и адаптивная разметка.
- `static/theme.css` и `static/theme.js` — сине-голубая палитра и переключатель светлой/тёмной темы.
- `run.ps1` — подготовка окружения и запуск приложения.
- `tunnel.ps1` — запуск Quick Tunnel на локальный сервер.
- `src/worker.py`, `src/cloudflare_d1.py`, `wrangler.jsonc`, `migrations/` — Cloudflare Worker и база D1.
- `tools/package_worker.py` — подготовка шаблонов и статики для публикации.
- `cloudflare.ps1` — запуск Wrangler с локальным Node.js.

База хранится в `instance/sportcenter.db` рядом с приложением. Для резервной копии останови сервер и скопируй этот файл.
