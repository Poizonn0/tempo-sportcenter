# Tempo

Демонстрационное web-приложение спортивного центра Tempo. Посетители смотрят расписание, создают аккаунт и записываются на тренировки. Администратор управляет расписанием, пользователями и записями.

## Сайт

Открыть: [tempo.sportcenter.workers.dev](https://tempo.sportcenter.workers.dev)

Сайт опубликован в Cloudflare Workers и работает независимо от компьютера владельца. Расписание и регистрации хранятся в Cloudflare D1.

## Что показать на паре

1. Главную страницу и сине-голубой дизайн Tempo.
2. Расписание и свободные места на занятиях.
3. Переключение светлой и тёмной темы.
4. Регистрацию клиента и запись на занятие.
5. Админ-панель с занятиями, участниками и выгрузкой CSV.

Демо-доступ администратора: `admin@sportcenter.local` / `admin123`. Используй только демонстрационные данные.

## Возможности

- Регистрация и вход, личный кабинет.
- Расписание занятий с фильтрами и доступными местами.
- Запись и отмена записи на тренировку.
- Панель администратора, управление пользователями и CSV-отчёт.
- Адаптивный интерфейс со светлой и тёмной темами.

## Технологии

- Python и Flask — страницы и бизнес-логика.
- Cloudflare Workers — запуск приложения в интернете.
- Cloudflare D1 — база данных на основе SQLite.
- HTML, CSS и JavaScript — интерфейс и переключатель темы.

## Запустить локально

Нужен Python 3.11+ и Windows PowerShell. В папке проекта выполни:

```powershell
.\run.ps1
```

Затем открой <http://127.0.0.1:5000>. Локальная версия использует SQLite в `instance/sportcenter.db`; Cloudflare-сайт продолжает работать отдельно.

## Опубликовать обновление в Cloudflare

Изменения в HTML, CSS и Python подготавливаются и отправляются командами:

```powershell
uv sync
uv run tools/package_worker.py
.\cloudflare.ps1 deploy
```

Если при первом запуске нет `tools/node-portable`, сначала выполни `uv run python tools/bootstrap_node.py`. Секрет сессий уже сохранён в Cloudflare и не хранится в файлах проекта.

## Структура проекта

- `src/app.py` — маршруты сайта, вход, расписание, записи и админ-панель.
- `src/worker.py` — точка входа Cloudflare Worker.
- `src/cloudflare_d1.py` — адаптер Flask для Cloudflare D1.
- `templates/` — HTML-шаблоны страниц.
- `static/` — оформление и скрипт темы.
- `migrations/` — создание таблиц и демонстрационные данные D1.
- `wrangler.jsonc` — настройки Worker, D1 и статических файлов.
- `app.py` и `run.ps1` — запуск локальной версии.
- `ПАМЯТКА_ДЛЯ_ПАРЫ.md` — короткое объяснение проекта и план показа.
