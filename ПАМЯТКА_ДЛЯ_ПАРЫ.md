# Tempo — памятка для показа

## Что показать преподавателю

Открой сайт: <https://tempo.sportcenter.workers.dev>.

1. На главной покажи, что это сайт спортивного центра Tempo.
2. Открой расписание, покажи карточки занятий и свободные места.
3. Переключи светлую и тёмную темы.
4. При желании зарегистрируй демонстрационного клиента и запиши его на занятие.
5. Покажи админ-панель: `admin@sportcenter.local`, пароль `admin123`. Там можно управлять занятиями, смотреть записи и выгружать CSV.

Используй только вымышленные данные. Для показа сайта не нужно запускать локальный сервер: приложение уже работает в Cloudflare.

## Как объяснить устройство проекта простыми словами

```text
Браузер
  → Cloudflare Worker (принимает запрос)
  → Flask/Python (выбирает нужную страницу и выполняет действие)
  → Cloudflare D1 (сохраняет пользователей, занятия и записи)
```

Cloudflare Worker работает как сервер в интернете. Flask обрабатывает страницы и формы. D1 — база данных SQLite-типа, хранящаяся в Cloudflare. Поэтому сайт доступен по постоянной ссылке, даже когда компьютер выключен.

## Какие файлы открыть в VS Code

Открой папку `SportCenter` через **File → Open Folder**.

- `src/app.py` — страницы и действия: регистрация, вход, расписание, записи, админ-панель.
- `src/worker.py` — входная точка Cloudflare Worker.
- `src/cloudflare_d1.py` — небольшой адаптер, который позволяет Flask обращаться к Cloudflare D1.
- `templates/` — HTML-разметка страниц.
- `static/` — CSS-оформление и JavaScript переключателя темы.
- `migrations/` — SQL-файлы, которые создают таблицы и демонстрационные занятия.
- `wrangler.jsonc` — настройки Cloudflare: имя Worker, привязка D1 и статические файлы.
- `app.py` и `run.ps1` — запуск локальной версии на компьютере.
